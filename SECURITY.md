# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Nexconn ChatUI. Users should upgrade to the latest compatible release before requesting a backport.

## Reporting a Vulnerability

Do not open a public GitHub issue for an unpatched vulnerability.

Send a private report to [support@nexconn.ai](mailto:support@nexconn.ai) with:

- The affected ChatUI version
- A clear description of the issue and impact
- Reproduction steps or a proof of concept
- Relevant browser, operating system, and dependency versions
- Any suggested mitigation

Nexconn will acknowledge the report, investigate it, and coordinate disclosure after a fix or mitigation is available. Please avoid accessing data that does not belong to you and do not disrupt production services while testing.
